# 💖 Happy Birthday, My Love! - Special Interactive Surprise Web

Website romantis interaktif untuk perayaan ulang tahun istimewa, dibuat dengan **HTML5**, **Tailwind CSS**, dan **Vanilla JavaScript** murni, siap di-hosting langsung secara gratis menggunakan **GitHub Pages**.

---

## ✨ Fitur-Fitur Utama

1. **🔐 Romantic PIN Gate (23102005)**
   - Proteksi kejutan dengan tanggal lahir: `23 Oktober 2005` (`23102005`).
   - Dilengkapi keypad virtual estetik bertema cinta, animasi berdenyut, dan pesan manis bila tanggal belum sesuai.

2. **🎂 Kartu Ucapan Ulang Tahun**
   - Sambutan hangat dengan nuansa warna *rose gold & blush pink*, partikel hati melayang di latar belakang, dan pengiring musik romantis.

3. **🎈 Level 1: Tangkap 10 Gelembung Hati**
   - 10 balon gelembung hati melayang dengan animasi fisika mengapung.
   - Saat disentuh/diklik: efek meletus (*pop*) dengan suara manis dan memunculkan kutipan kata-kata cinta puitis di titik letusan.

4. **💭 Level 2: Kuis Romantis 'Seberapa Kenal Kita?'**
   - Pertanyaan pilihan ganda interaktif tentang hubungan dan kenangan manis.
   - Jika memilih jawaban yang kurang pas, muncul dialog pop-up manis ("*Hampir tepat sayang, tapi cintaku lebih dari itu!*").

5. **🃏 Level 3: Temukan Pasangan Kartu Cinta**
   - Permainan memori 12 kartu (6 pasang simbol cinta: Mawar, Cincin, Surat, Boneka, Kue, Kado).
   - Animasi flip kartu 3D, live stopwatch timer, dan apresiasi romantis saat selesai.

6. **📸 Galeri Polaroid & Lightbox**
   - Tampilan foto-foto kenangan berbingkai polaroid klasik dengan selotip washi tape dan tulisan tangan indah (*Dancing Script*).
   - Klik foto untuk membuka mode *fullscreen lightbox* dengan cerita di balik setiap foto.

7. **💌 Surat Cinta Ajaib (Typewriter Effect)**
   - Amplop bergaya vintage dengan segel lilin (*wax seal*).
   - Saat diklik, amplop terbuka dan kertas surat meluncur keluar.
   - Kata-kata surat romantis muncul per huruf (*typewriter animation*) seperti sedang diketik langsung dari lubuk hati.

8. **🎁 Kado Ulang Tahun & Ledakan Konfeti Penuh Layar**
   - Kotak kado 3D berdenyut dengan pita berkilau.
   - Saat diklik: memicu ledakan konfeti warna-warni, bintang, dan pita memenuhi seluruh layar dengan ucapan puncak ulang tahun!

## 🚀 Panduan Hosting ke GitHub Pages (Gratis & Mudah)

Ikuti langkah-langkah mudah berikut untuk mengunggah dan mengaktifkan website ini di GitHub:

### Langkah 1: Inisialisasi Git & Commit
Buka terminal / command prompt di folder proyek ini (`birthday`), lalu jalankan:

```bash
git init
git add .
git commit -m "feat: romantic birthday surprise website"
git branch -M main
```

### Langkah 2: Buat Repositori di GitHub
1. Buka [github.com](https://github.com) dan login ke akun Anda.
2. Klik tombol **New** (Buat Repositori Baru).
3. Beri nama repositori, contoh: `birthday` atau `for-my-love`.
4. Pilih **Public** (agar GitHub Pages gratis bisa aktif).
5. Jangan centang "Add a README file" karena kita sudah memilikinya.
6. Klik **Create repository**.

### Langkah 3: Hubungkan dan Push ke GitHub
Salin URL repositori yang baru Anda buat, lalu jalankan perintah:

```bash
git remote add origin https://github.com/<username-anda>/<nama-repo>.git
git push -u origin main
```

*(Ganti `<username-anda>` dan `<nama-repo>` sesuai akun GitHub Anda)*

### Langkah 4: Aktifkan GitHub Pages
1. Di halaman repositori GitHub Anda, klik menu **Settings** (di kanan atas).
2. Di sidebar sebelah kiri, klik menu **Pages**.
3. Di bagian **Build and deployment**:
   - **Source**: Pilih `Deploy from a branch`
   - **Branch**: Pilih `main` dan folder `/(root)`
4. Klik tombol **Save**.
5. Tunggu sekitar 1–2 menit, refresh halaman. Link website Anda akan muncul di bagian atas:
   `https://<username-anda>.github.io/<nama-repo>/`

Website sudah aktif dan siap dibagikan ke orang tersayang! 💕
